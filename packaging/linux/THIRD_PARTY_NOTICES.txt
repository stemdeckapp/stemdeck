System Requirements (Not Bundled)
---------------------------------

FFmpeg is not bundled in the Linux package. On first launch StemDeck downloads a
static FFmpeg build into your user data directory (or uses a system `ffmpeg`
already on your PATH). The download is fetched directly from the upstream
provider, not redistributed by StemDeck. FFmpeg may be distributed under LGPL or
GPL terms depending on how the build was compiled.

WebKitGTK and GTK shared libraries are provided by your Linux distribution and
are not bundled. They are distributed under LGPL terms.

Demucs model weights are not bundled. They are downloaded during first use.
StemDeck should display the model source and license/usage terms before or
during download.

Separation model weights are not bundled either. They are downloaded when a
song first uses them, into the models folder, and are not redistributed by
StemDeck:

- Mel-Band RoFormer vocals model by Kimberley Jensen (the Kim model). License:
  MIT, as its model card declares. StemDeck downloads one pinned revision and
  checks its SHA-256. Source: https://huggingface.co/KimberleyJSN/melbandroformer
  It runs through audio-separator (MIT).
- Demucs fine-tuned models (htdemucs_ft), from the same Demucs project as the
  Demucs entry above. License: MIT (Meta/Facebook Research).
  Source: https://github.com/facebookresearch/demucs

FFmpeg (GPL build)
------------------
StemDeck downloads FFmpeg at first run and calls it as a separate
executable. It is not linked into StemDeck and does not change
StemDeck's own license.

Build: ffmpeg-release-amd64-static, from johnvansickle.com/ffmpeg
License: GNU General Public License v3 or later
         https://www.gnu.org/licenses/gpl-3.0.html

Written offer of source. The complete corresponding source, along with
the build's own readme naming its configure flags, is published beside
the binary:

  https://johnvansickle.com/ffmpeg/
  https://git.ffmpeg.org/ffmpeg.git

If either link stops resolving, open an issue at
https://github.com/stemdeckapp/stemdeck/issues and the source will be
provided by another means.

Chromaprint fpcalc
------------------
For song fingerprinting, when the FFmpeg in use has no chromaprint support,
StemDeck downloads Chromaprint's fpcalc 1.6.1 (the upstream release build)
beside FFmpeg and calls it as a separate executable. It is not linked into
StemDeck.

License: GNU Lesser General Public License v2.1 for Chromaprint as a
         whole (its own code is MIT); the binary includes FFmpeg's
         libraries.
         https://github.com/acoustid/chromaprint/blob/v1.6.1/LICENSE.md
Source:  https://github.com/acoustid/chromaprint/releases/tag/v1.6.1
         https://git.ffmpeg.org/ffmpeg.git
