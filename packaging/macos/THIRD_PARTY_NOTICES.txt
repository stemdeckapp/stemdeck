THIRD-PARTY NOTICES
===================

StemDeck for macOS uses a thin Tauri app plus a downloaded runtime pack.

Bundled in StemDeck.app:

- Tauri v2
- The system WebKit WebView provided by macOS

Downloaded during first-run setup:

- StemDeck runtime pack containing Python and Python package dependencies
- FFmpeg and ffprobe
- Chromaprint's fpcalc, when the FFmpeg in use has no chromaprint support
- Demucs model weights

The runtime pack carries the full inventory under licenses/. INDEX.txt there
lists every packaged Python dependency with its version and license, and each
entry's own license text sits beside it. It is generated from the packaged
interpreter at build time rather than maintained by hand, so it describes what
actually shipped.

FFmpeg
------
StemDeck downloads FFmpeg and ffprobe at first run and calls them as
separate executables. They are not linked into StemDeck and do not
change StemDeck's own license.

Build: ffmpeg 8.1.1 and ffprobe 8.1.1, from evermeet.cx
License: GNU General Public License v3 or later
         https://www.gnu.org/licenses/gpl-3.0.html

Written offer of source. The complete corresponding source is:

  FFmpeg itself, release 8.1.1
    https://git.ffmpeg.org/ffmpeg.git
  The build's configuration, reported by `ffmpeg -version`
    https://evermeet.cx/ffmpeg/

If either link stops resolving, open an issue at
https://github.com/stemdeckapp/stemdeck/issues and the source will be
provided by another means.

Chromaprint fpcalc
------------------
For song fingerprinting, StemDeck downloads Chromaprint's fpcalc 1.6.1
(the upstream release build) beside FFmpeg and calls it as a separate
executable. It is not linked into StemDeck.

License: GNU Lesser General Public License v2.1 for Chromaprint as a
         whole (its own code is MIT); the binary includes FFmpeg's
         libraries.
         https://github.com/acoustid/chromaprint/blob/v1.6.1/LICENSE.md
Source:  https://github.com/acoustid/chromaprint/releases/tag/v1.6.1
         https://git.ffmpeg.org/ffmpeg.git

OpenCC character table
----------------------
License: Apache License 2.0
Website: https://github.com/BYVoid/OpenCC
StemDeck folds traditional Chinese characters to simplified ones when it
compares artist and song names, so lyrics filed under either are found.
The table (app/_vendor/opencc/zh_t2s.txt, and the same pairs in
static/js/zhVariants.js) is derived from OpenCC's TSCharacters.txt,
Copyright Carbo Kuo (BYVoid) and the OpenCC contributors: only the first
simplified form of each character is kept. The license text is
app/_vendor/opencc/LICENSE.
